## 되짚을 만한 판단

- **테스트를 포팅보다 먼저 만들었다** (`plan.md` §1). 결과적으로 포팅은 첫 실행부터 일치했고,
  회귀 테스트로 보존할 최소 재현 케이스가 하나도 생기지 않았다.
- **검증을 2스테이지로 나눴다** (`plan.md` §8.1). FSM 을 `TODO()` 스텁으로 두고
  비-FSM 물리를 먼저 전수 검증 → FSM 의 RNG 소비 버그를 격리할 수 있는 상태를 만들었다.
- **`INFINITE_LOOP_LIMIT` 은 도달 불가로 확인하고 케이스를 만들지 않았다** (`plan.md` §6.4).
  커버리지 숫자를 위해 밟을 수 없는 분기에 케이스를 만드는 것은 검증이 아니다.
- **데이터는 공유하고 로직은 복제한다** (`plan.md` §6.4). 입력 생성기는 양쪽에 복제해
  하네스로 대조하지만, 표적 케이스 표는 한 파일을 함께 읽는다.
